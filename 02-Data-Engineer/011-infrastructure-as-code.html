011Infrastructure as Code

Met Infrastructure as Code (Terraform, Bicep, CloudFormation) beschrijf je cloud-resources in code, zodat omgevingen reproduceerbaar, reviewbaar en automatisch uit te rollen zijn.

VisueelJunior & seniorPraktijkBegrippenDetailValkuilenOefenen

01Visueel

02Junior & senior

Junior – de kern
  • Terraform: werkt op alle clouds (HCL-taal). Bicep: Azure. CloudFormation: AWS.
  • Declaratief: je beschrijft de gewenste eindtoestand, de tool regelt de stappen.
  • Zelfde code → dev, test, prod met andere variabelen.
  • Voorkomt 'klikken in de portal' dat niemand kan herhalen.
Senior – de diepte
  • State (Terraform) veilig remote opslaan met locking.
  • Modules voor hergebruik (standaard data-landingzone).
  • Uitrol via CI/CD-pipelines (Azure DevOps/GitHub Actions) met goedkeuring voor prod.
  • Policy as code, drift-detectie; secrets nooit in code.

De productie-workspace van een zorginstelling wordt per ongeluk verkeerd geconfigureerd in de portal. Omdat alles in Terraform staat, laat terraform plan precies zien wat er afwijkt en zet apply het binnen minuten terug.

04Begrippen

Declaratief
Je beschrijft de eindtoestand, niet de stappen.
State
Terraform's administratie van wat er bestaat.
Module
Herbruikbaar blok IaC-code.
Drift
Werkelijkheid wijkt af van de code.
Bicep
Azure-taal voor IaC.

05In detail

HCL
resource "azurerm_resource_group" "data" {
  name     = "rg-data-${var.omgeving}"
  location = "westeurope"
}

resource "azurerm_storage_account" "lake" {
  name                     = "stlake${var.omgeving}"
  resource_group_name      = azurerm_resource_group.data.name
  location                 = azurerm_resource_group.data.location
  account_tier             = "Standard"
  account_replication_type = "ZRS"
  is_hns_enabled           = true          # ADLS Gen2
}

Mogelijke interviewvraag

“Waarom zou je een Databricks-workspace met Terraform aanmaken in plaats van via de portal?”

Eerst zelf antwoorden – dan klik voor de antwoordrichting
  • Reproduceerbaar voor dev/test/prod.
  • Review en audit via Git – belangrijk bij overheid.
  • Snel herstel bij problemen en geen configuratie-drift.
